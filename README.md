# 🛠️ 3D Printing Cost Calculator & Inventory System

ระบบคำนวณต้นทุนราคาขายและจัดการคลังสินค้า (Stock) สำหรับงาน 3D Printing พัฒนาขึ้นด้วย **Google Apps Script** และ **HTML/CSS/JS (Web App)** ช่วยให้คนรักงานพริ้นท์ 3D สามารถคำนวณราคาขายตามน้ำหนักฟิลาเมนต์ ระยะเวลา และค่าเสื่อมเครื่องได้อย่างแม่นยำ พร้อมระบบตัดสต็อกในตัว!

> **💡 Fun Fact:** โปรเจกต์นี้วางโครงสร้างและพัฒนาอย่างรวดเร็วผ่านคำสั่งบน Terminal ด้วย **Gemini CLI** 

---

## ✨ ฟีเจอร์เด่น (Features)
* 💰 **Cost Calculator:** คำนวณต้นทุนฟิลาเมนต์ (PLA+, PETG, ฯลฯ) ตามน้ำหนักที่ใช้จริง (กรัม) พร้อมบวกค่าไฟและค่าเสื่อมเครื่องอัตโนมัติ
* 📦 **Inventory Management:** ระบบบันทึกสต็อกฟิลาเมนต์ ม้วนไหนใช้ไปเท่าไหร่ รู้ได้ทันที
* 📈 **Profit & Pricing:** แนะนำราคาขายที่เหมาะสม พร้อมสรุปกำไรต่อชิ้นงาน
* 🖥️ **Friendly UI:** หน้าตาใช้งานง่าย คลีน สะอาดตา ลื่นไหลในรูปแบบ Google Sheets Web App

## 📦 วิธีการนำไปใช้งาน (Setup Guide)

1. **เตรียม Google Sheets:** สร้าง Google Sheets ขึ้นมาใหม่ 1 ไฟล์
2. **เปิด Apps Script:** ไปที่เมนู **ส่วนขยาย (Extensions)** -> **Apps Script**
3. **วางโค้ดระบบ:**
   * ก๊อปปี้โค้ดจากไฟล์ `Code.gs` ไปวางในหน้าหน้าต่างรหัสของ Apps Script
   * สร้างไฟล์ HTML ใหม่ใน Apps Script ตั้งชื่อว่า `Index.html` แล้วนำโค้ดจากไฟล์ `Index.html` ในโปรเจกต์นี้ไปวาง
4. **เปิดใช้งาน Web App:** กดปุ่ม **ทำให้ใช้งานได้ (Deploy)** -> **การทำให้ใช้งานได้ใหม่ (New Deployment)** เลือกประเภทเป็น **เว็บแอป (Web App)**
5. **เริ่มใช้งาน:** ก๊อปปี้ URL ที่ได้ไปเปิดใช้งานและคำนวณราคาได้เลย!
